# 痛苦地图 · pain-atlas

> 把一段痛苦体验或一个流派追问，转成「判型 → 流派对位 → 一手出处 → 出路」四段结果。

这是一个 WorkBuddy / 兼容 SKILL.md 规范的 AI 技能包。它把"痛苦"这个模糊词拆成可定位的结构问题：属于哪一类、深到哪一层、对应哪个流派、出处在哪里、有哪条路可走。

## 它解决什么问题

常见做法是把痛苦按情绪命名——焦虑、抑郁、emo。这种命名不产生任何可执行的信息。

这个包换一种切法：按**成因 ＋ 体验维度**分成肉身性、认知性、存在性、关系性四型，再把四型对位到东西方思想谱系上，每条给出可核对的一手著作与篇目，最后给一条与这个痛苦结构相匹配的路。

它不承诺"治愈"，也不做哲学综述。它做的是定位。

## 三种交付形态

| 形态 | 用户怎么说 | 交付物 |
|---|---|---|
| 分析 | "我最近特别难受说不上来为什么" | 四段式分析卡 |
| 考据 | "斯多葛怎么看待痛苦，原文在哪一段" | 引证清单 |
| 成稿 | "帮我把这段写成能发的笔记" | 去 Markdown 标记的成稿 |

默认走分析。用户一句话即可切换。

## 快速开始

```bash
# 1. 克隆
git clone https://github.com/Nakiku-ovo/pain-atlas.git

# 2. 拷进技能目录
cp -r pain-atlas/pain-atlas ~/.workbuddy/skills/

# 3. 重启 WorkBuddy，然后直接说话
```

装好后不需要记命令，正常提问即可触发：

- 「我这种痛苦算哪一种」
- 「叔本华和尼采的路，我该走哪条」
- 「帮我查一下舍勒论痛苦，给到篇目」

## 数据自检

改过谱系表，或从别处拿到这个包时，先跑一次：

```bash
python scripts/atlas_query.py --verify
```

它会拦下四类问题：条目数低于下限、ID 断号或重复、必填字段缺失、等级或四型取值越界。不通过就不要拿它做对位——一个截断的资料表会让判型静默漏条，而输出看起来仍然正常。

## 谱系覆盖

50 条，编号 G01–G50，横跨：

- 东方哲学（道家、儒家、佛教）
- 古希腊哲学（柏拉图、亚里士多德、斯多葛、伊壁鸠鲁）
- 近代哲学（笛卡尔、休谟、叔本华、尼采、康德、黑格尔）
- 现象学（胡塞尔、舍勒、列维纳斯）
- 结构主义与后结构主义（索绪尔、列维-斯特劳斯、拉康、德里达、福柯、德勒兹、利奥塔）
- 存在主义（虚无主义、加缪、萨特、海德格尔）
- 分析哲学（维特根斯坦、心灵哲学、帕菲特、威廉斯）
- 马克思主义、宗教学（基督新教、天主教、伊斯兰教、犹太教、印度教）
- 精神分析、现代心理学、社会学、神经科学、功利主义
- 以及一条标注为「作者框架」的自建整合模型

## 引证等级

每一条出处都标等级，等级决定这句话能不能加引号、能不能说"某思想家认为"。

| 等级 | 含义 |
|---|---|
| `A` | 能定位到篇/章/节，且该处确实论证了所述内容 |
| `B` | 只到著作级，或需依赖二手转述，或原典与所述内容只是相关 |
| `C` | 仅书名/论文名可给，或属当代理论簇无单一原典 |
| `—` | 作者框架，不入引证体系 |

两条硬规则：

1. **「命题」栏是推演性读法，不是原话。** 「痛苦来自【X】」回答的是"这一派会怎么看痛苦"，不是"这一派说过痛苦来自 X"。
2. **一律引节号，不引页码。** 中译本页码随印次变化，引节号才稳定。

## 四型是受控词表

判型、检索、谱系表的「四型」栏，只允许四个词：**肉身性、认知性、存在性、关系性**。

「四型全覆盖」「四型收束」这类整体性描述单独放在「覆盖」栏，不写进四型。原因很实在：检索是按四型做集合匹配的，一旦把描述性文字混进去，那条会在四个型里全部筛不到——输出看起来正常，但整条谱系被静默跳过。

## 示例输出

```
【判型】主：存在性 ｜ 辅：关系性
【追问】你要的是"我说出口的话是我自己的话"，而这个位置要的是"你代表这个位置说话"。
【对位】主：萨特 ｜ 辅：福柯
　命题：痛苦来自【自由的绝对性与责任的独担性】｜推演自《存在与虚无》的自欺
　出处：《存在与虚无》第一部分第二章 ｜ 等级 A
【出路】醒 —— 认出"我在演总监"不是被逼的，是我每天在选择继续演。
【代价】收回之后，VP 的安全感不能再用来解释自己。
【边界】萨特不处理结构性约束。若问题其实是"这岗位不许说实话"，那是福柯那一路。
```

## 边界

**它不做什么：**

- 不诊断精神疾病，不给药物、剂量、停药建议
- 不编造引文，不生成页码，不把概述加引号冒充原文
- 不做流派优劣排名
- 命中自伤、自杀、伤人信号时**停止一切分析**，转接危机资源（中国大陆：12356 全国统一心理援助热线，依据国卫医政函〔2024〕259 号；该热线每日提供不少于 18 小时服务，非 24 小时）

## 依赖

核心流程零依赖——只需要一个能读 Markdown 的模型。

`scripts/atlas_query.py` 需要 Python 3.8+，属可选：没有它时直接读 `references/genealogy.md`，结果等价。

## 来源与作者框架

本包的谱系骨架整理自作者自撰的《各流派痛苦观之汇编》，并在此基础上补齐了原稿缺失的书目、修正了编纂本与转述混淆的引证、标注了每条常见误引。

`G50`「内外结构错位」是作者自建的整合框架，**不是学界共识**，包内已明确标注；引用时请一并标明来源为个人框架。
