# 痛苦地图

把"痛苦"这个模糊词拆成可定位的结构问题：它属于哪一类、深到哪一层、对应哪个流派、出处在哪里、有哪条路可走。

## 三种交付形态

| 形态 | 用户怎么说 | 交付物 |
|---|---|---|
| 分析 | "我最近特别难受说不上来为什么"、"这种痛苦算哪一种" | 四段式分析卡 |
| 考据 | "斯多葛怎么看待痛苦，原文在哪"、"帮我查一下舍勒" | 引证清单 |
| 成稿 | "帮我把这段写成能发的笔记" | 去标记的成稿 |

默认走分析。用户一句话即可切换，不必追问。

## 五条硬规则

1. **危机优先**。出现自伤、自杀、伤人、无法维持基本生活的信号时，停止一切分析，转入 `references/crisis-boundary.md` 的流程。分析让位于安全，没有例外。
2. **不编造引文**。任何一句被写成"原话"的引文，必须能交代到具体著作与篇目；交代不到就降到著作级，并写明"仅到著作级"。不生成页码，不虚构章节，不把概述加引号冒充原文。
3. **区分原典与推演**。谱系表中的「命题」栏多数是从该流派核心理论推演出的读法，不等于该思想家本人的原话。写"海德格尔认为痛苦来自被抛"是错的，写"从海德格尔的沉沦与畏可以推出"才对。
4. **作者框架要署名**。`G50` 的「内外结构错位」是使用者自建的整合框架，不是学术共识。用到时必须写明这是个人框架。
5. **不做排名**。「哪派最高明」不回答；改答"以你现在的处境，哪一派的读法更贴"。

## 执行流程

### 步骤 0：危机筛查

先扫一遍用户原话有没有这些信号：明确的自杀或自伤念头、告别式表达、具体计划与手段、持续两周以上的功能崩解、物质滥用、精神病性症状。

命中任意一项 → 不做判型、不做对位、不给哲学出路 → 按 `references/crisis-boundary.md` 输出。这一条不因用户说"我就是想聊聊哲学"而豁免。

### 步骤 1：定形态

- 用户描述的是自己的处境 → 分析
- 用户问的是某一派、某一本书、某个概念的出处 → 考据
- 用户要成品 → 成稿（先做分析，再把分析写成稿）

用户没说清楚时按"分析"走，不要先问。

### 步骤 2：判型

按 `references/typology.md` 的四型表判定。规则：

- 最多写两个：一个主型、一个辅型（标"主 / 辅"）。
- 主型是痛感的主要成分，不是引发事件的性质。被裁员引发的不一定是关系性痛苦，可能是存在性。
- 三型以上并存时，只保留用户原话里证据最硬的两个，其余在"边界"里一句带过。

### 步骤 3：抽追问

把痛点压成一句"……却……"的结构：**你要的是 X，而 Z 不允许**。这是分析卡里唯一必须原创的一句，也是决定后面选哪条路的关键。写法与反例见 `references/typology.md`。

### 步骤 4：对位

打开 `references/genealogy.md`，按「四型」栏筛出候选，再按追问结构选一个主、一个辅。检索方式见本文末。

选主对位的标准，按优先级：

1. 该流派的「命题」与步骤 3 的追问结构同构
2. 该流派承认这条痛苦的不可消除性（不承诺速愈）
3. 该流派的出路动作是用户当下做得到的

不要因为"这个流派有名"而选它。

### 步骤 5：给出路

按 `references/paths.md` 给**一条**路，说清动作、代价、以及它在什么条件下不适用。用户明确要比较时才给两到三条，并说明选择判据。

### 步骤 6：组装

按下面的模板输出。分析卡控制在 600—900 字；考据清单不限，但每条不超过四行。

## 分析卡模板

```
【判型】主：X ｜ 辅：Y
【追问】你要的是 ____，而 ____ 不允许。
【对位】主：____ ｜ 辅：____
　命题：痛苦来自【____】　｜　推演自：____
　出处：《____》____ ｜ 等级 A/B/C
【出路】____ —— 一句话说清要做的动作
【代价】走这条路要放弃什么
【边界】这条读法不处理什么；什么时候该换人（医生、咨询师、律师）
```

### 填好的示例

用户原话："每天上班像在扮演一个不是自己的人，回家就空掉了。"

```
【判型】主：存在性 ｜ 辅：关系性
【追问】你要的是"过一种属于自己的生活"，而你要靠这份工作活着——这就是你的追问。
【对位】主：海德格尔 ｜ 辅：福柯
　命题：痛苦来自【被抛沉沦与有限性】　｜　推演自：《存在与时间》的沉沦与畏
　出处：《存在与时间》§38 沉沦、§40 畏、§46–53 向死存在 ｜ 等级 A
【出路】醒 —— 先把"别人都在过的那种日子"认出来是逃避，而不是默认设置。
【代价】认出之后不会立刻变好，反而会先更难；本真不是舒适状态。
【边界】海德格尔的"畏"不是焦虑症；如果你已经出现持续失眠、无法工作，这条读法不适用，先看医生。
```

## 引证清单模板

```
【一手】《____》（原文名 ____）
【篇目】____（篇/章/节号，或对话篇名）
【术语】原文词 ____ ＝ 中译 ____
【要点】该处到底论证了什么，两行以内
【等级】A / B / C，理由
【误引】常见的错读是什么
【译本】推荐的译本；页码怎么处理
```

### 填好的示例

用户原话："海德格尔说的畏，原文到底在哪？"

```
【一手】《存在与时间》（Sein und Zeit, 1927）
【篇目】§40「畏这一基本现身情态作为此在别具一格的展开状态」
【术语】die Angst ＝ 畏；与 die Furcht（怕）严格区分
【要点】畏之所畏者不是世内某个存在者，而是"在世本身"；所以畏没有具体对象，也就无法通过消除某个对象来消除。
【等级】A——节号可核对，论证要点在原节内
【误引】把"畏"当临床焦虑症，或当"害怕某件事"，两者都错。
【译本】陈嘉映、王庆节译（商务印书馆）。引节号不引页码，中译本页码随印次变。
```

## 成稿规则

用户要"能发出去的成品"时：

1. 先照上面的模板做一份分析，但**不要把分析卡直接交给用户**。
2. 把分析改写成连续散文：首句就是判断，不铺垫，不写"在这个快节奏的时代"。
3. 去掉所有 Markdown 标记：不要 `#` 标题、不要 `**` 加粗、不要项目符号、不要编号列表。
4. 段落之间空一行；一段一个意思，不超过四行。
5. 不写"希望对你有帮助""愿你被世界温柔以待"这类收尾。
6. 引用只在必要处出现，写法是《书名》＋篇目，不加引号不装原话。
7. 成稿默认 400—700 字。用户指定字数则从之。

## 检索谱系表

两种方式，按环境选一种。

**有 Python 时**（推荐，结果稳定）：

```bash
python scripts/atlas_query.py --type 存在性 --level A
python scripts/atlas_query.py --keyword 畏
python scripts/atlas_query.py --list
```

参数：`--type` 按四型过滤；`--category` 按类别过滤；`--level` 按引证等级过滤；`--keyword` 全文匹配；`--list` 只输出 ID 与名称。多个条件同时给时取交集。

**没有 Python 时**：直接读 `references/genealogy.md`，按 `类别` 与 `四型` 两个字段目视筛选。结果等价，只是慢。

## 验收清单

交付前逐条过：

- [ ] 没有出现任何无法交代到著作的"原话"
- [ ] 每条出处都标了 A/B/C，且等级与实际精度相符
- [ ] 推演性的命题写成了"从……可以推出"，没有写成"某思想家认为"
- [ ] 判型不超过两个，且主辅分明
- [ ] 追问写成了一句"……却……"，不是一段复述
- [ ] 只给了一条出路，并写了代价
- [ ] 写了"这条读法不处理什么"
- [ ] 用到 G50 时标注了"个人框架"
- [ ] 成稿形态下没有残留 Markdown 标记

## 停止条件

出现以下情况，停止当前输出并说明原因，不硬给结论：

- 命中危机信号 → 转 `references/crisis-boundary.md`，不再回到分析
- 用户要的是诊断、用药、剂量、停药建议 → 明确说明超出范围，建议精神科
- 用户问的流派不在谱系表内且无法核实其一手著作 → 说明"表内无此条目"，给出你能确认的部分，标"未验证"
- 用户要求"编一句像样的引文" → 拒绝，改给著作级定位
- 用户要求对某流派做优劣裁决 → 转为"适配条件"回答

## 降级

| 情况 | 处理 |
|---|---|
| 无 Python | 直接读 `references/genealogy.md`，结果等价 |
| 无法联网 | 只用表内已核条目；用户要求核实版本、页码、新译本时，明说"未联网核对" |
| 表内无对应条目 | 用最近邻的两个条目做类比，明确标"类比，非该派原典" |
| 用户语言非中文 | 术语栏保留原文词，书名给原文名，篇目沿用原书编号体系 |
